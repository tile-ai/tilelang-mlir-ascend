# 大工作集自适应 L2 分段与 KV-head 优先排布

## 适用症状与触发条件

- 短序列/小工作集下 MFU 与流水已经很理想，但序列拉长（如 4K–64K）或工作集超过 L2 有效驻留容量后，出现以下特征：
  - `msprof` 中部分核总时长明显拉长（核间长尾），但各核 Cube 忙时几乎一致；
  - 慢核的 **AIC L2 读命中率显著偏低**（例如跌至 45%–75%），伴随 `MTE2` 耗时飙升与大量长空泡。

## 核心物理机理

1. **未超 L2 容量时：按 `KV-head → KV-tile` 排列全局工作前缀**
   - 避免不同核在同一时间窗口内分散访问过多无关的 `Q`/`K`/`V` 切片，提高同组 GQA head 对 `Q/dO/K/V` 在 L2 中的共享命中率。
2. **超 L2 容量时：零 ABI 改动的自适应分段（`G_sec`）**
   - 当估算活跃工作集超过硬件 L2 驻留阈值时，沿 Q-head 或序列维度划分子段（例如按规模动态选择分段因子 `G=8/4/2/1`），让所有核先集中消费同一段工作集，大幅缩短数据复用距离。
   - **收益/代价权衡**：缩短复用距离可显著拉升 L2 读命中率（典型可提升至 92%–96%+）并消除大部分长空泡；代价是少量 `K/V` 重载或部分和原子写回，因此分段数必须随工作集自适应，不能对所有尺寸一刀切。

## 关键注意点

- **不要为了“静态均衡”破坏 L2 局部性**：将原本连续的 tile 打散做全局轮转均衡，可能把核间极差压到 1.01×，却让 L2 read miss 暴涨数倍导致端到端反而变慢。
- **区分重放 L2 指标与热启动驻留**：`msprof op` 插桩重放的 L2 命中率不能直接等同于连续热启动的驻留状态，但同批同口径对比对诊断相对局部性改善极具价值。

## 验证清单

- 先用 CPU 覆盖测试验证所有长度与分段因子下的任务全覆盖、零遗漏、零重复。
- 实卡覆盖中等长度（2K–8K）与超长序列（16K–64K），同时检查 L2 读/写命中率、长空泡计数与端到端同批热时延，确保短序列无回退。
